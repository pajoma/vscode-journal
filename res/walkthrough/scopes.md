# A scope: `#acme`

A scope is a project of your journal: a tag and a folder (`scopes/acme`).

## Its plan, `scopes/acme/Plan.md`

```markdown
# Plan #acme

## Discovery
- [/] interviews
  - [x] interview guide (done: 2026-11-13 10:00) [[2026-11-13]]
  - [ ] invite participants
- [ ] report
```

## Today's entry

```markdown
- [ ] #acme interviews [[Plan]]
  - [ ] invite participants
```

Work on the copy in your journal. With task sync on, the copy has a key (`#acme:5`), and completing it completes the plan item. Ctrl+click on `#acme` shows the report of the scope: its plan, its notes and the work of the last days.
