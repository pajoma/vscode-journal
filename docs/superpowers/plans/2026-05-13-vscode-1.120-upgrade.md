# VS Code 1.120 Upgrade Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Bump vscode-journal from VS Code 1.94 baseline to 1.120 in three independently revertable layers — dependency bump, manifest cleanup, and `vscode.l10n` migration — without touching unrelated PLAN.md phases.

**Architecture:** Three sequential commits on a single feature branch (`feature/vscode-1.120-upgrade` off `develop`). Layer 1 bumps `engines.vscode`, `@types/vscode`, TypeScript, esbuild, ESLint, `@vscode/test-cli/electron`, and Mocha. Layer 2 edits `package.json` only — drops the redundant `activationEvents` block, removes the unused `@vscode/extension-telemetry` dependency, and adds a `capabilities` block declaring `virtualWorkspaces: "limited"` and `untrustedWorkspaces: false`. Layer 3 replaces the custom `messages.json` + `translations.ts` translation system with VS Code's stable `vscode.l10n` API: `package.nls.*.json` for manifest strings, `l10n/bundle.l10n.*.json` for runtime strings.

**Tech Stack:** TypeScript 5.x, esbuild, ESLint 9 (flat config), `@vscode/test-cli` + Mocha (TDD UI), VS Code Extension API ≥1.120, `vscode.l10n`, `@vscode/l10n-dev`.

**Spec:** `docs/superpowers/specs/2026-05-13-vscode-1.120-upgrade-design.md`
