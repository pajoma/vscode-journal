### 2. CHANGELOG.md — add 4 missing entries (item A)

**Added:**
- `[Issue #145]` `journal.memo` — dedicated command "Enter Quick Memo" registered as an alias for the smart input so users can bind it to a separate key or invoke it from the command palette independently from `journal.day`.

**Fixed:**
- `[Issue #170]` Word-boundary anchoring on smart-input weekday / month tokens. Entering text that begins with a locale-specific day abbreviation (e.g., "Do" for Donnerstag) no longer triggers premature date parsing. PR #178.

**Changed:**
- `[Issue #187]` Cold-start latency of the smart-input picker eliminated. `ScanEntries` now returns the cached entry list on second and subsequent invocations without re-walking the filesystem. Cache is invalidated by VS Code file-system events. PR #191.
- `[Issue #188]` Maintainability: `var→const`, dead console.log removed, `getScopeDefinitions()` / `getNavigationMode()` added to `Configuration`, full `async/await` migration of `conf.ts`, DRY helpers (`isRemoteSession`, `toLocalFileUri`) centralised in `util/paths.ts`, `InsertMemoCommand` consolidated into startup registration. PR #192.

*Why: release CHANGELOG must be complete and accurate for every shipped code change. Tests (#190) and docs (#181) are omitted — these are developer-facing, not user-facing release notes.*
