# Spec: Docs refresh — keybindings + configuration (#181)

## Goal

Bring `docs/commands.md` and `docs/settings.md` fully in sync with `package.json` before the 1.1.0 release, add missing cross-references across feature docs, and create a new `docs/weekly-entries.md` page for the weekly workflow added in #168 and #185.

## Why now

Multiple features landed since the docs were last audited (#51 remote fix, #144 prev/next navigation, #168 entry granularity, #185 weekly sync, #188 quick wins). Release milestone 1.1.0 is blocked on accurate docs (issue body: "until this issue is closed, the docs do not accurately describe what ships"). The smoke-test checklist (#180) references keybindings and settings that are either wrong or missing.

## In scope

### A. `docs/commands.md` — keybindings audit

- Fix command-id syntax throughout: `journal:day` → `journal.day` (colon is wrong).
- Add `journal.printDuration` (`Ctrl+J D` / `Cmd+J D`) with `when: editorTextFocus && editorHasMultipleSelections`.
- Add `journal.printSum` (`Ctrl+J S` / `Cmd+J S`) with same `when` clause.
- Add `when: editorTextFocus` note to `openPrevious` / `openNext`.
- Add Mac-equivalent column/note for all bindings.
- Add section: how to rebind via `keybindings.json` (example snippet for a journal command).
- Add locale coverage paragraph: command titles and prompts are localized via `vscode.l10n`; list the eleven supported locales (en, de, fr, es, it, pt, nl, ru, zh, ja, ar).
- Fix `docs/print.md`: wrong shortcuts listed as `Ctrl+J Ctrl+D` / `Ctrl+J Ctrl+S` — actual bindings are `Ctrl+J D` / `Ctrl+J S`.
